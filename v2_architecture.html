再生成ループ (regenerate)
↩ hitl_topics → regen → topics ← 新トピック一覧を再取得
↩ hitl_titles → regen → titles ← 同一トピックでタイトル再生成
↩ hitl_sources → regen → research ← 8ソースを再調査
↩ hitl_outline → regen → outline ← アウトライン再生成
↩ hitl_draft → regen → draft ← フィードバック/戦略付きで再生成
↩ hitl_final → regen → draft ← QA戦略(Deep Fix/Balanced/Structural)で再生成

✅ QA 10項目チェック

構造: 語数 1,000〜1,500
構造: エグゼクティブサマリー ~100語
構造: ボディセクション ≥3件
証拠: 引用 [N] ≥3件
証拠: 数値+引用セット ≥3件
批判分析: 比較 ≥2オルタナティブ
批判分析: アンチ推奨 >50語
批判分析: TCO分析 >50語
技術深度: 物理的制約 ≥2キーワード
文体: 箇条書き禁止 (段落のみ)

🎯 再生成戦略 (最大3つ)

🎯 Deep Fix
最も失敗の多いカテゴリに集中して修正
⚖️ Balanced Revision
全カテゴリのQA失敗を均等に修正
🔄 Structural Rewrite / Citation Fix
構造失敗→全体再構成 / 証拠失敗→引用強化
selected_strategy.guidance → node_draft の qa_feedback へ注入
Exec Node — ツール実行 (非同期, to_thread)
HITL Node — interrupt() で停止、ユーザー入力待ち
approve → 次フェーズへ進む
regenerate → 同フェーズを再実行
Checkpointer: MemorySaver (dev) / SqliteSaver (prod推奨)
